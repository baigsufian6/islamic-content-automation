# Islamic Content Automation — Source Register

This document records every external source used by the project.

No source may be used for final publication unless its status and intended
use have been verified.

---

# 1. Qur'an Arabic Text

## Primary source

Name:
Quran Foundation Content API

Website:
https://api-docs.quran.com/

Purpose:
- Qur'an chapter information
- Qur'an verse information
- Arabic text
- Verse metadata
- Verse ranges
- Recitation metadata where available

Status:
ACCESS REQUEST SUBMITTED

Final production approval:
PENDING

Notes:
API credentials must never be committed to GitHub.

---

## Independent Arabic cross-check

Name:
Tanzil

Website:
https://tanzil.net/

Purpose:
Independent verification of Qur'an Arabic text.

Status:
CANDIDATE — VERIFICATION REQUIRED

Notes:
Tanzil text licensing and attribution requirements must be followed if
the source is used.

---

# 2. English Qur'an Translation

Status:
NOT SELECTED

Requirements:

- Established published translation
- Identifiable translator
- Identifiable source/version
- Appropriate publishing rights
- Exact ayah correspondence
- No AI-generated translation for final publication

The translation must be selected and verified before production videos are
published.

---

# 3. Qur'an Recitation

Preferred reciter:

Shaykh Saad Al-Ghamdi

Status:
SOURCE / LICENCE VERIFICATION REQUIRED

Requirements:

- Exact reciter identity verified
- Exact ayah correspondence verified
- Publishing rights verified
- Social-media use permitted
- Commercial/non-commercial terms understood
- Long-term use conditions understood

No random YouTube, social-media, or audio download may be used merely because
the recording is available online.

---

# 4. Hadith Sources

Status:
NOT YET SELECTED

Requirements:

- Recognized Hadith source
- Exact collection identified
- Book/chapter/reference identified where available
- Hadith number/reference identified where appropriate
- Arabic text verified
- Translation source identified
- Authenticity/grade information verified
- Scholarly context handled carefully

AI must not determine Hadith authenticity by itself.

---

# 5. Visual Sources

Possible categories:

- Original generated visuals
- Properly licensed stock footage
- Properly licensed images
- Original motion graphics
- Islamic architecture
- Qur'an manuscripts/calligraphy where legally usable
- Abstract cinematic environments

Requirements:

- Publishing rights verified
- No visible human faces
- No depiction of prophets or other unseen religious figures
- No misleading depiction of unseen realities
- Visual must be appropriate to the ayah
- No watermarks in final production

---

# 6. Fonts

Arabic font:
NOT YET SELECTED

English font:
NOT YET SELECTED

Requirements:

- Arabic rendering must be correct
- Licence must permit intended use
- Font must remain readable on mobile
- Font must support required Arabic characters and marks

---

# 7. Source Status Definitions

PENDING
Source has not yet been fully verified.

CANDIDATE
Potential source identified but not approved.

VERIFIED
Source and intended use have been checked.

APPROVED
Source is approved for production use.

RETIRED
Source must no longer be used for new production.

---

# 8. Golden Rule

If the system cannot establish where a religious text, translation, audio
recording, or other important source came from, it must not automatically
publish it.

UNKNOWN SOURCE = DO NOT PUBLISH
