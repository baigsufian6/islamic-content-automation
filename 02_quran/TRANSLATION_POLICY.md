# Qur'an English Translation Policy

## 1. Purpose

This document defines how English translations of Qur'an meanings are
selected, verified, stored, displayed, and published.

The translation is not Qur'an itself.

It is an English rendering of the meanings of the Qur'an.

---

# 2. Primary Candidate

Saheeh International

Candidate distribution/source:

QuranEnc.com

Translation key:

english_saheeh

Status:

CANDIDATE — PENDING FINAL PRODUCTION APPROVAL

---

# 3. Why This Candidate

The candidate is suitable for investigation because:

- It is an established English translation.
- QuranEnc provides ayah-level structured access.
- QuranEnc provides translation version information.
- QuranEnc provides source/translation metadata.
- QuranEnc publishes explicit terms for republication.

No final production use is permitted until the current version and
republication requirements have been recorded.

---

# 4. Translation Integrity

The final published translation must be reproduced exactly according to
the approved source/version.

The system must NOT:

- rewrite the translation
- paraphrase the translation
- simplify the translation
- shorten the translation
- combine translations
- insert AI-generated words
- remove words
- add explanatory words inside the translation

---

# 5. AI Policy

AI may help with:

- organization
- metadata
- comparison
- quality-control checks

AI must NOT rewrite the approved English translation.

AI-generated English must never silently replace the approved translation.

---

# 6. Verse Correspondence

Every translation record must have:

- Surah number
- Ayah number
- Verse key
- Translation text
- Translation source
- Translation version

Example:

22:13

The translation displayed for 22:13 must be the approved translation
record belonging to 22:13.

---

---

# 8. Attribution

The published video/caption/description must provide attribution according
to the source's current republication requirements.

Attribution must not be hidden in a way that violates the source terms.

---

# 9. Source Terms

Before production approval, verify the current QuranEnc republication
terms.

Required checks include:

- modification prohibited
- addition prohibited
- deletion prohibited
- source attribution
- version attribution
- transcript information requirements
- update requirements
- advertising restrictions

---

# 10. Updating

If the translation source releases a newer approved version, the project
must record the new version.

Existing published videos must NOT be silently altered.

New videos should use the current approved version after verification.

---

# 11. Translation Source Failure

If the translation source becomes:

- unavailable
- legally unsuitable
- discontinued
- inaccessible
- materially changed

the system must stop new production using that source.

It must NOT silently substitute another translation.

---

# 12. Independent Review

The translation is an English rendering of Qur'anic meanings and is not
treated as infallible.

The project must not claim that an English translation is the Qur'an
itself.

---

# 13. Footnotes

If the approved source supplies footnotes or explanatory material, the
system must not automatically merge those notes into the translation text.

Footnotes must be treated as separate metadata.

---

# 14. Display Rule

Arabic Qur'an text and English translation appear together on the same
video frame.

The English translation must remain clearly identifiable as a translation.

---

# 15. Long Translation

If the English translation is too long for the available display area:

DO NOT make the text unreadably small.

The system must:

1. attempt professional multi-line layout
2. preserve the exact translation
3. maintain readability
4. flag the item for review if necessary

The system must never truncate the translation.

---

# 16. Translation Change Control

Any change to:

- translator
- translation source
- translation version
- translation key

requires:

1. documentation
2. verification
3. updated Source Register
4. updated configuration
5. new production verification

---

# 17. Core Rule

The English translation must be:

EXACT
TRACEABLE
VERSIONED
PROPERLY ATTRIBUTED
UNMODIFIED

If any of these cannot be established:

DO NOT PUBLISH.
